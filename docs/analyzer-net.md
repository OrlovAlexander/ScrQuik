# Нейронка по парным связкам

Продолжение `--odds` / `*AnalyzerOdds`: те же RPM и такт M1. На вход — **связкаД1Н4**, **связкаН4М30**, **связкаМ30М10**. У каждой связки сеть видит цепочку из трёх соседних пачек старшего ТФ и цепочку из трёх соседних пачек младшего. Оверлей odds не развивать.

Это не `*AnalyzerMarks` и не сетапы комбо. Комбо `buy`/`sell` анализатора **не меняются**: сеть их только видит как признак вместе с числами RPM.

Исходник: [`analyzer/net.py`](../analyzer/net.py). Веса: `C:\QuikFinam\LuaIndicators\analyzer_net\net.npz`. Определения тега, пачки, связки и кадра: [tag-packs.md](tag-packs.md).

## На чём построена

Те же линии, что на живом графике QUIK. Ряд M1 — CSV barsSaver. **M10/M30/H4/D1 строят из этого M1** на каждой минуте (OHLC слота на этот момент). Закрытый слот фиксируют из M1 в момент закрытия; внутри слота пачка — только минуты до `t`. CSV старших ТФ — только сверка вычисленного бара **на закрытии** слота, не вход сети. Правило: [tf-from-m1.md](tf-from-m1.md).

- на каждом ТФ один RPM-current (FIR + EMA 90) и один RPM-up из `config/RPM_TF_Up_5.ini` по ТФ **графика** (H4: H12/D1/W1, D1: D5/W2/W5);
- паттерн 121 на сеть не подаётся (он только на M30 у меток);
- теги те же: `vs0`, `vs_ema`, `slope`, `ema_vs0`, `ema_trend`, `hist_sign`, `hist_dir`;
- шкала z — медиана модуля **этого** инструмента, не чужой кусок истории.

Объекты:

- **тег** — одно свойство RPM на формирующемся баре одного ТФ;
- **пачка** — ≥5 тегов одного бара одного ТФ, такт пересчёта **M1**;
- **связка** — **связкаД1Н4**, **связкаН4М30**, **связкаМ30М10**;
- **кадр** — на шаге M1 три связки; у каждой цепочка из 3 пачек старшего ТФ и цепочка из 3 пачек младшего;
- **цепочка** одного ТФ — 3 соседних бара **того же** ТФ.

Обучение: все инструменты barsSaver (сейчас 52), фьючерсы SPBFUT в выборке повторяются ×4. MLP 128×64, лосс — режим + **три** головы ahead, L2, ранняя остановка по balanced acc режима и ahead на хвосте каждого инструмента. Головы действия нет. Базу и lift сеть не считает. Доли исхода у пачки или парной связки — не эта модель. `--odds` сюда эволюционировал и сам по себе не развивается.

## Что видит на входе

Такт сборки пачек — **M1**, и на истории тоже. **Кадр** = три парные связки на этом M1, не пять ТФ. У **связкаД1Н4** на вход идут цепочка из 3 соседних пачек D1 и цепочка из 3 соседних пачек H4; у **связкаН4М30** — 3 H4 + 3 M30; у **связкаМ30М10** — 3 M30 + 3 M10. Соседний бар — бар **этого** ТФ. Пачка M1 в кадр не входит. Старшие бары из M1 на минуту кадра. Закрытый CSV внутрь слота не подставляют.

Итого на вход MLP — **6 векторов пачек одной связки** (2 ТФ × 3 бара), 34 числа каждый: **204** (`CHAIN_BARS=3`, `IN_DIM=204`). Три связки не склеивают в один вектор: иначе веса D1–H4 не переносятся на M30–M10. Старый вход 612 (три связки подряд) снят.

На живом графике предсказание пересчитывают каждую минуту. Обучение смешивает **отдельные** связки в одну сеть с **общим стволом** (`IN_DIM=204`, одна связка = 6 пачек). Живой кадр прогоняет ту же сеть по каждой присутствующей связке. Действие и пунктир — **одно** среднее трёх softmax ahead (головы `Wa` нет). Как из этого ставят круг — [ниже](#точка-обучение-и-живой-график).

Предвидение на истории **разное по связке**, метка не вход. **Такт строки — всегда M1** (как live), не закрытие M5/M30. Окно — от этой минуты по ряду M1:

| связка | такт обучения | окно вперёд от этой M1 | это |
|---|---|---|---|
| **связкаМ30М10** | каждый **M1** | **10** M1 | один M10 |
| **связкаН4М30** | каждый **M1** | **6** M5 = **30** M1 | один M30 |
| **связкаД1Н4** | каждый **M1** | **8** M30 = **240** M1 | один H4 |

Смотрят high/low путь этих следующих M1 относительно close текущей минуты. Порог `ahead_flat` — медиана экскурсии **того же окна** на M1 этого инструмента × 0.25 (не шаг одной минуты). Иначе сторона с большей экскурсией. Не ждут закрытия M5/M30, чтобы положить строку в выборку. Если до правого края меньше **240** M1, строку не берут: нет долгосрочного ahead.

### Вектор одной пачки

- числа RPM current / small / middle / hist и шаги (`d_rpm`, `d_ema`, `d_hist`), нормированные z шкалы этого инструмента;
- знаки: `vs0`, `vs_ema`, `slope`, `ema_vs0`, small/middle vs0, `hist_sign`, `hist_dir`;
- one-hot сетапа комбо: `none` / `buy` / `sell` / `buy1` / `sell1` / `buy2` / `sell2`;
- `miss_hist_buy` / `miss_hist_sell` — недорисованный стек без растущей hist;
- `pack_bias` — направление **пачки** (среднее голосов тегов, не один `current.vs0`);
- `layer_div_buy` / `layer_div_sell` — расхождение small/middle;
- `pack_ok` — пачка набрала ≥5 тегов.

Пачка без RPM current — нули и `pack_ok=0`. Связка без годной **текущей** пачки обоих её ТФ в выборку этой пары не идёт. Другие связки того же инструмента всё равно обучаются.

## Головы

Ствол общий (`W1`/`W2`). Режим — голова MLP (на графике её не рисуют). Предвидение — **три** головы по 3 класса, по одной на связку. На строке лосс ahead только у головы этой пары. **Головы действия (`Wa`) нет: не учат и не рисуют.**

| выход | значения |
|---|---|
| режим | `flat` / `impulse` / `pullback` (на графике — с пачек, не softmax) |
| предвидение связкаМ30М10 | `ahead_flat` / `ahead_up` / `ahead_down` на **10** M1 — краткосрок |
| предвидение связкаН4М30 | то же на **30** M1 — среднесрок |
| предвидение связкаД1Н4 | то же на **240** M1 — долгосрочник |

**Режим на графике не из softmax MLP.** Его считают с пачек RPM: current старшего ТФ (H4, иначе M30) против M1. Старший в сторону, M1 с ним — импульс; M1 против — откат; старший у нуля — флет. На M10/M30 доли ещё усредняют внутри слота бара и сглаживают EMA (`REGIME_EMA=8`), чтобы линия не пилила 0↔100. На точку режим **не влияет**.

## Точка: обучение и живой график

**Точка** (`buy_in` / `sell_in`) — не голова MLP и не сетап комбо. Сеть учит только три предвидения пути. Круг на индикаторе ставят **после** прогона: равное среднее трёх softmax и порог. `Wa` нет.

### Что учится

Разметка **не** «когда комбо buy» и **не** «2R раньше стопа за 120 M1». На минуте `t` по ряду M1 считают три **факта пути** (`ahead_label`):

| срок | связка | окно вперёд от этой M1 |
|---|---|---|
| краткосрок | **связкаМ30М10** | 10 M1 |
| среднесрок | **связкаН4М30** | 30 M1 |
| долгосрочник | **связкаД1Н4** | 240 M1 |

От close минуты `t` смотрят high/low следующих M1 окна. Порог флета — медиана такой экскурсии **того же окна** на этом инструменте × 0.25 (`FLAT_FRAC`). Если обе стороны меньше порога — флет, иначе сторона с большей экскурсией. Не ждут закрытия M5/M30, чтобы положить строку в выборку.

Каждая голова ahead учится **своему** факту. На строке лосс ahead только у головы этой пары. Если до правого края меньше **240** M1, минуту не берут. Короткой связкой строку не добирают.

Голосование трёх фактов (сколько из трёх окон ушло вверх / вниз / во флет) пишут в лог. **В лосс не идёт.** Этим голосованием точку на графике не ставят.

Сетапы комбо, отказ hist и расхождение small/middle — **поля вектора пачки**, не условие точки и не метка ahead.

### Как из трёх голов получают сторону (live и `--net`)

Живой кадр прогоняет ту же сеть по каждой присутствующей связке. У пары берут **её** голову (softmax: флет / вверх / вниз). Дальше равное среднее:

`P = (голова_10 + голова_30 + голова_240) / 3`

Нет любой из трёх пар — среднего нет, точки нет (`action` = `none`).

Правило (`action_from_ph_mean`, `ACTION_MIN=0.45`, `ACTION_GAP=0.08`):

1. Победитель — строго максимум среди флет / вверх / вниз.
2. Ничья или победил флет → нет точки.
3. Доля победившей стороны ≥ **45%** и на **8%** выше противоположной (вверх против вниз, не против флета).
4. Вверх → `buy_in`, вниз → `sell_in`. Выходов нет: `buy_out` / `sell_out` в CSV всегда 0.

Без сетапа, без вето режима, без вето одной головы, без запасного входа.

Те же три доли среднего пишут в `ahead_up` / `ahead_down` / `ahead_flat` и в колонки `buy_in` / `sell_in` (проценты 0…100, не круги). Поле `action` — уже `buy_in` / `sell_in` / `none` после порога. На каждом ТФ пунктиры **одинаковые** (не голова «этого» графика).

На **M1, H4 и D1** поле `action` обнуляют: кругов нет, пунктиры остаются.

На **M10 и M30** линии слота — среднее минут внутри слота; **`action` — с последней M1 этого слота**. Круг на M10 — решение последней минуты десятиминутки, не среднее десяти решений.

### Живой слот

`--watch-net` каждую минуту пересчитывает пачки из M1 и прогоняет сеть. Закрытые строки CSV **не переписывают**; живой только формирующийся слот. На открытом M10/M30 точка может появиться, сдвинуться или пропасть с каждой M1 — ограничение такта, не повод подставлять закрытый бар внутрь слота. См. [tf-from-m1.md](tf-from-m1.md).

### Что рисует Lua

`*AnalyzerNet` круги не считает. Читает CSV и ставит точку на уровне **33**, если график M10 или M30, `action` = `buy_in` или `sell_in`, и доля стороны в CSV ≥ 45 с зазором 8 к противоположной (тот же порог ещё раз). Пунктиры — те же три доли среднего.

## Запуск

Нужен `numpy`. Сначала веса (`--train-net`), потом CSV для графика.

```text
python -m analyzer --train-net
python -m analyzer --sec CNY12.26 --net
python -m analyzer --watch-net --sec CNY12.26
```

`--net` пишет CSV в `C:\QuikFinam\LuaIndicators\analyzer_net\{SEC}_{CLASS}_{ТФ}.csv` (M1/M10/M30/H4/D1). Без `--sec` — все инструменты. `--watch-net` обновляет файлы по тикам M1 (окно не закрывать, простой 11 с). После снятия `Wa` лосс другой: `python -m analyzer --train-net`. Старый `net.npz` с одной головой ahead не подходит. `Wa` в файле, если есть, не читают.

## Индикатор

Скопировать [`lua/AnalyzerNet.lua`](../lua/AnalyzerNet.lua) в:

`C:\QuikFinam\LuaIndicators\AnalyzerNet.lua`

На графике **M1**, **M10**, **M30**, **H4** или **D1**:

1. Добавить `*AnalyzerNet` **отдельным окном** (не на ценовую панель).
2. Снять старый с цены, если висел там. После замены lua — снять и навесить снова.
3. Линия **0** фиксирует низ шкалы; линию 100 не рисуют.

| линия | что |
|---|---|
| flat | синяя — доля «флет» режима (с пачек, не ahead) |
| buy_in / sell_in | точки на уровне **33** — сторона среднего трёх ahead (только M10 и M30) |
| ahead_up | голубая пунктир — доля вверх **среднего** трёх голов |
| ahead_down | розовая пунктир — доля вниз того же среднего |
| ahead_flat | сиреневая пунктир — доля флета того же среднего |

Линии `impulse` / `pullback`, гистограмму uncertain и рельс 100 на окне **не рисуют**. После замены lua — снять индикатор и навесить снова (**7** линий). `ReloadSec = 15`. Навесьте индикатор и на M10.

Три пунктира — **склеенное** среднее 10 / 30 / 240 M1, одинаковое на всех ТФ графика. Не голова «следующего бара» этого ТФ. Точка — порог по тому же среднему.
