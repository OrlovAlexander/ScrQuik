# Настройки и использование

## Параметры дивергенций

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `1_Small_DivDraw` | 0 | Дивергенции слоя Small |
| `2_Midle_DivDraw` | 0 | Дивергенции слоя Midle |
| `3_Up_DivDraw` | 0 | Дивергенции слоя Up |

`1` — включено, `0` — выключено. Не зависит от `*_Draw` (линии RPM).

Гистограммы (отдельно):

| Параметр | По умолчанию |
|----------|--------------|
| `1_Small_HistDraw` | 0 |
| `2_Midle_HistDraw` | 0 |
| `3_Up_HistDraw` | 0 |

---

## Пример конфигурации пользователя

- **График:** H4  
- **Слои:** Small = H6, Midle = H8, Up = D1  
- **DivDraw:** все = 1  

Pivot'ы ищутся по сегментам агрегированных TF; фракталы цены — на H4.

## Установка

1. Скопировать `lua/RPM_TF_Up_5.lua` → `C:\QuikFinam\LuaIndicators\`
2. Убедиться, что `lua/maLib.lua` лежит в `C:\QuikFinam\LuaIndicators\`
3. Добавить индикатор `*RPM_TF_Up_5` на график
4. Включить нужные `*_DivDraw`
5. Снять и навесить индикатор после обновления файла

На живом графике параметры слоёв (TF / Period / Draw / HistDraw) берутся из окна QUIK, не из `config/RPM_TF_Up_5.ini`. Ini нужен Python-анализатору; его можно обновить скриптом `tools/one2one/extract_rpm_up_ini.py` из `finam.wnd` (пачка Small=`D5` пишется в секцию `[RPM_TF_Up_5.D1]`).

Живая раскладка (одна на все инструменты, секция по ТФ **графика**):

| график | Small | Middle | Up | HistDraw |
|---|---|---|---|---|
| M1 | Mn5 | Mn10 | Mn20 | Up |
| M10 | Mn20 | Mn30 | H2 | Small |
| M30 | H1 | H2 | H4 | Up |
| H4 | H12 | D1 | W1 | Up |
| D1 | D5 | W2 | W5 | Up |

Строка слоя (`1_Small_TF`, `2_Middle_TF`, `3_Up_TF`) — одно из:

- минуты: `Mn2` `Mn3` `Mn4` `Mn5` `Mn6` `Mn10` `Mn15` `Mn20` `Mn30`
- часы: `H1` `H2` `H3` `H4` `H6` `H8` `H12`
- дни: `D1` `D2` `D3` `D4` `D5` — D2–D5 это слот из N календарных суток (как H2/H4 из часов). Граница слота — unix-день Lua `floor(os.time({year,month,day,hour=12})/86400)`, не Python `toordinal()`. Иначе пятидневки сдвигаются на 3 дня и гистограмма не совпадает с графиком.
- недели: `W1` `W2` `W3` `W4` `W5` — W1 новый бар в понедельник; W2–W5 слот из N недель `floor((dayNumber-4)/7)` (unix day 0 = четверг 1970-01-01, понедельник = день 4).
- `M1` (месяц)

Слой должен быть старше ТФ графика.

Цвет гистограммы (`*_HistDraw`): зелёный столбик растёт относительно предыдущего бара (`histUp`), оранжевый — короче или равен (`histDw`). Это направление, не знак относительно нуля.

## Почему линий может не быть

1. **Мало истории** — мало подтверждённых сегментов на старших TF.
2. **Строгий фрактал** — `DIV_PRICE_PERIOD = 5` на TF графика; экстремум цены должен совпасть с pivot RPM в сегменте.
3. **Буфер 4** — видны только последние 4 дивергенции слоя.
4. **Dash + тот же цвет** — линии малозаметны на фоне RPM.
5. **Инвалидация** — пробой цены/RPM после формирования сигнала убирает линию.

## Подстройка порогов

В начале блока дивергенций в `lua/RPM_TF_Up_5.lua`:

```lua
DIV_EXTENDED_PCT   = 0.003   -- тип II: «двойная вершина/дно»
DIV_WEAK_RPM_PCT   = 0.015   -- тип III: RPM flat
DIV_WEAK_PRICE_PCT = 0.005   -- тип III: активное движение цены
DIV_PRICE_PERIOD   = 5       -- период фрактала цены
DIV_SEG_PERIOD     = 1       -- окно pivot по сегментам RPM
```

Для волатильных инструментов можно увеличить `DIV_EXTENDED_PCT` и `DIV_WEAK_*`.

## getSetting и ноль

```lua
local function getSetting(Fsettings, key, altKey, default)
    local v = Fsettings[key] or Fsettings[altKey]
    if v == nil then
        return default
    end
    return v
end
```

Значение `0` корректно читается как «выключено».
