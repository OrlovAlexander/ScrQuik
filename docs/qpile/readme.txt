Набор примеров программ на QPILE. 
К каждой из них прилагается краткая инструкция.  
Программы разбиты на две категориии:  для трейдера и для брокера.

Для брокера
client_value.qpl - подсчет объема операций по выделенным клиентам
delays.qpl - протоколирование задержек поступления торговой информации на
Рабочее место
margin_trade.qpl - протоколирование уровней маржи при совершении сделок
клиентами
market_activity.qpl - отображение текущей активности рынка
rts_vs_micex.qpl - сравнение оборота на разных площадках
sec_my_value.qpl - расчет доли брокера в обороте по бумаге
kknd.qpl -  поиск потенциальных "тамагочеров" на рынке фортс.
limit_saver.qpl -   портфель один раз в день в указанное время сохраняет все денежные и бумажные лимиты в файл, который потом можно загрузить из клиентского терминала


Для трейдера
assets.qpl - отображение изменения текущих активов клиента изо дня в день
indexes.qpl - сводая таблица индексов МБ и РТС
portfolio.qpl - прибыли/убытки по клиентским позициям
quote_export.qpl - экспорт bid/offer по инструментам в текстовый файл
spread.qpl - отображение спреда между фьючерсными контрактами и базовым активом
all_trade_color.qpl -   подсветка строчек в таблице обезличенных сделок в зависимости от направления (покупка\продажа)
buy_sell_ratio.qpl -   подсчитывается объёмы купли\продажи по определённому инструменту за заданный интервал   
fort.qpl -  расчёт ликвидационной стоимости портфеля на срочном рынке 
monitor.qpl -  портфель предназначен для построения произвольных пользовательских оповещений. Подробная инструкция по настройке в файле monitor.doc 
option_scanner.qpl - портфель сканирует опционы и отыскивает контракты у которых цена превышает ГО
