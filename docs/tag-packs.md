# Теги, пачки, связки, цепочки и цепочка связок

## Тег

**Тег** — дискретная метка **одного** свойства RPM на **закрытом** баре одного ТФ: слой + поле + одно значение из короткого списка.

Пример: `M1.current.vs0 = above_0` — один тег. Не тег: сырое число RPM (`0.42`), цена, сетап `buy`/`sell` (сетап — комбинация нескольких тегов).

Слои как на графике: `current` (RPM этого ТФ), `small` / `middle` / hist-слой RPM-up. Поля: `vs0`, `vs_ema`, `slope`, `ema_vs0`, `ema_slope`, `ema_trend`, `hist_sign`, `hist_dir`. Значения вроде `above_0`, `below_ema`, `falling_above_ema`, `hist_growing`. Словарь — в [analyzer-marks.md](analyzer-marks.md). Считает `analyzer/states.py`.

Один тег сам по себе не картина и не фильтр.

## Пачка

**Пачка** — набор **не меньше пяти** тегов, которые относятся к **одному закрытому бару одного ТФ**. Все теги пачки с этой же свечи, не с соседних и не с другого ТФ.

Не пачка: один тег, два–четыре тега, теги с разных баров, теги с разных ТФ, один сетап `buy`/`sell`.

Пример (пять тегов одного M1-бара): `M1.current.vs0` + `M1.current.vs_ema` + `M1.current.slope` + `M1.small.vs0` + `M1.hist_dir`.

На каждом ТФ у каждого бара своя пачка.

## Цепочка

**Цепочка** — последовательность пачек **одного ТФ** на соседних закрытых барах в окне истории. Это динамика пачки от свечи к свече: какая была, на какую сменилась, сколько баров держалась.

Окна: M1 **40**, M10 **30**, M30 **30** закрытых баров. Цепочка не пачка (пачка — один бар) и не связка (связка — разные ТФ в один момент).

Не цепочка: снимок только последнего бара; прыжок через дырки в истории; смешение баров разных ТФ в одном ряду.

## Связка

**Связка** — набор **двух или более пачек разных ТФ одного инструмента**, снятых по закрытым барам на один момент времени. Старший ТФ смотрит закрытую историю младших до своего открытия (M10 17:20 → M1 до 17:19).

Связка не пачка: в пачку чужой ТФ не кладут. Согласованность и противоречие пачек внутри связки — часть одной картины, не отдельные кейсы.

Пример: пачка M1 + пачка M10 + пачка M30.

Не связка: пачки разных инструментов; один ТФ; набор тегов с M1 и M10 без того, чтобы на каждом ТФ набралась своя пачка ≥5.

`--combo` в CLI строит дерево уникальных состояний H4→M1 — это не связка пачек.

## Цепочка связок

**Цепочка связок** — последовательность **связок** на соседних закрытых барах **ведущего** ТФ. Ведущий ТФ задаёт такт: каждый его закрытый бар — один **кадр**, в кадре лежит целая связка, не одна пачка.

Это не три независимые цепочки рядом и не одна длинная пачка. Это один ряд кадров одного инструмента: какая связка была, на какую сменилась, сколько кадров держалась целиком, какой слот (какой ТФ) внутри связки сдвинулся раньше.

Ведущий ТФ обычно M10 или M30. В кадре: пачка этого закрытого бара ведущего ТФ плюс пачки младших `last_closed` до его открытия (M10 17:20 → M1 до 17:19). Несколько M1 внутри одного M10 — тот же кадр, пока M10 не закрылся; это не новые кадры цепочки связок (динамика M1 внутри кадра — обычная цепочка M1).

Окно считают по ведущему ТФ: M10 **30** / M30 **30** закрытых баров. Если ведущий M30, младшие в каждом кадре тоже `last_closed` к открытию этого M30.

Не цепочка связок: цепочка одного ТФ; одна связка (снимок момента); три цепочки без общего такта; смесь тегов с разных ТФ в один список; прыжок через дырки в истории ведущего ТФ.

## Похожесть

Порог похожести (например 80%) применяют **не** к уже посчитанным значениям тегов. Сначала берут **числа с живого графика**, затем **пересчитывают теги**.

![с живого last_closed снимают числа и шкалу, z сравнивают с порогом 80%, теги пересчитывают; Hamming по меткам — не похожесть](images/tag-similarity.svg)

С last_closed живого графика снимают величины слоёв, из которых делают теги: RPM `current` / `small` / `middle`, EMA, hist, шаги. Шкала — медиана модуля **этого** окна (`NEAR_*` в [analyzer-marks.md](analyzer-marks.md)). Исторический бар нормируют тем же знаменателем:

```text
z = число / шкала_живого
sim_поля = 1 − |z_ист − z_живой| / max(|z_ист|, |z_живой|, 1)
sim      = среднее sim_поля по RPM, EMA, hist и шагам
```

В выборку бар попадает при `sim ≥ 80%`. Теги на нём считают заново классификатором `analyzer/states.py` на живой шкале. Пачка после пересчёта по-прежнему ≥5 тегов **одного** закрытого бара одного ТФ. Связка — по пересчитанным пачкам каждого ТФ, не смесь тегов.

Пример, D1 CNY-12.26 last_closed 29.09.2026: `current.rpm = −0.0386`, шкала `median(|current.rpm|) = 0.1001`, **z = −0.0386 / 0.1001 = −0.385**. На 28.09 тем же знаменателем `z = −0.227`, sim поля `0.84`. Теги `vs0=below_0` против `near_0` при Hamming разошлись бы.

Не похожесть: Hamming по готовым меткам («16 из 20 тегов совпали», `below_0` против `near_0` как 0/1). Не подставлять медиану чужого окна истории вместо шкалы живого графика.

## Доля

Исход (вниз / вверх / флет) считают среди баров, где есть эта **пачка** или эта **связка** (в том числе после пересчёта тегов по похожести). По **цепочке** и по **цепочке связок** смотрят смену и удержание в окне (пачки — от свечи к свече, связки — от кадра к кадру), не долю «по всем барам». Базу и lift не считают.

## Не путать

В логе `--watch` «пачка» — очередь грязных тикеров (до 21 с), не пачка тегов.
