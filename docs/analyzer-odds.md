# `--odds` эволюционировал в сеть

Оверлей `--odds` / `*AnalyzerOdds` **не развивать**. Его продолжение — [`analyzer-net.md`](analyzer-net.md): `--train-net` / `--net` / `--watch-net`, `*AnalyzerNet`.

Кадр odds — ведущий ТФ вниз до M1 (плюс D1). Это не **парная связка**. Объект связки — **связкаД1Н4**, **связкаН4М30**, **связкаМ30М10**. Паттерны и доли — у пачки или у этой пары, см. [tag-packs.md](tag-packs.md). Сеть берёт кадр из трёх парных связок (у каждой две цепочки по 3 пачки), не кадр odds.

Код (`analyzer/odds.py`, `lua/AnalyzerOdds.lua`) оставлен: общие функции (агрегация M1, `tf_numeric`) импортируют net и pack-ahead. Новый анализатор на оверлее odds не строить — строить на сети.

# Вероятности исхода на M10, M30 и H4 (архив)

Отдельный анализатор: доля исхода вверх / вниз / флет **следующего** бара ведущего ТФ.
История и живой кадр — один механизм: сигналы считают **динамически**, дискретность **M1**. Старшие бары из M1 (на минуте внутри слота — OHLC слота на этот момент; на закрытии — сверка с CSV ведущего ТФ). Живая точка может меняться с каждой M1 — ограничение такта, не повод подставлять закрытый бар внутрь слота ([tf-from-m1.md](tf-from-m1.md)).
Индикатор `*AnalyzerOdds` рисует три линии вероятности. Сетапы buy/sell и `*AnalyzerMarks` не затрагиваются.

Исходник: [`lua/AnalyzerOdds.lua`](../lua/AnalyzerOdds.lua), расчёт [`analyzer/odds.py`](../analyzer/odds.py).

## Что должно быть запущено

| # | Что | Зачем |
|---|---|---|
| 1 | QUIK + **barsSaver** | пишет **M1** (из него строят M10/M30/H4/D1) и старшие CSV **для сверки на закрытии** |
| 2 | `python -m analyzer --watch-odds` (или разовый `--odds`) | считает доли и пишет CSV |
| 3 | индикатор **\*AnalyzerOdds** на графике **M10**, **M30** или **H4** | три линии на левой шкале 0…100 |

M1 и D1 индикатор не рисует: при установке на другой ТФ линии пустые.

## Такт

M10, M30 и H4 считаются **по отдельности**. Живой кадр — формирующиеся бары от ведущего ТФ вниз до M1 (и формирующийся D1). Это **не** парные связки D1–H4 / H4–M30 / M30–M10.

`--watch-odds` грязнит **M1**, M10, M30 и H4. Один тик M1 (и первый poll со всеми грязными файлами) пересчитывает **сразу три** ведущих ТФ, без повторных проходов M10/M30/H4. Закрытие старшего слота входит в тот же проход.

На каждой исторической минуте — свой кадр ведущий→M1. Исход в выборке — закрытие **следующей** свечи того же ведущего ТФ **справа от этой минуты**. Флет, если ход меньше **четверти медианы** |Δclose| этого ТФ. Если похожих нет, живая точка тянется к равному приору (~33/33/33) через EMA. Один аналог (n=1) тоже не рисует 100% — Лаплас. Датавремя строки CSV — **открытие слота**, как у формирующейся свечи QUIK.

## Кадр (как было)

Связка на такте ведущего ТФ (этот ТФ вниз до M1, плюс D1):

| ведущий | в кадре |
|---|---|
| M10 | пачка M10 + M1 + **формирующийся D1** |
| M30 | пачка M30 + M10 + M1 + **формирующийся D1** |
| H4 | пачка H4 + M30 + M10 + M1 + **формирующийся D1** |

Цепочка связок — окно ведущего ТФ **3** соседних кадра. Похожесть — порог **60%**.

Поиск похожей **пачки** формирующегося D1 на D1/H4/M30 — отдельная команда `--pack-ahead` (не часть архива odds). См. [tag-packs.md](tag-packs.md#похожая-пачка-d1-на-d1--h4--m30).

## Запуск

```text
python -m analyzer --sec CNY12.26 --odds
python -m analyzer --watch-odds --sec CNY12.26
python -m analyzer --watch-odds
python -m analyzer --sec CNY12.26 --pack-ahead
```

`--odds` — разовая выгрузка. `--watch-odds` — грязные **M1**/M10/M30/H4. Окно не закрывать. Простой 11 с. CLI напоминает, что продолжение — `--net`.

CSV:

`C:\QuikFinam\LuaIndicators\analyzer_odds\{SEC}_{CLASS}_{ТФ}.csv`

`datetime;up;down;flat;n` — up, down и flat от 0 до 100, `n` — размер выборки. На график пишутся последние ~400 баров ведущего ТФ.

Пример: `CR_SPBFUT_M30.csv`.

## Индикатор

Скопировать `lua/AnalyzerOdds.lua` в:

`C:\QuikFinam\LuaIndicators\AnalyzerOdds.lua`

На графике **M10**, **M30** или **H4**:

1. Добавить `*AnalyzerOdds`.
2. Поставить **на ценовую панель** (тот же график, что свечи).
3. В свойствах привязать линии к **левой шкале**. Служебные линии **0** и **100** фиксируют шкалу процентов.

Линии:

| линия | цвет | значение |
|---|---|---|
| up | зелёная | вероятность исхода вверх |
| down | красная | вероятность исхода вниз |
| flat | синяя | вероятность исхода флета |

После замены lua снять индикатор и навесить снова. `OddsDir` пустой — папка `LuaIndicators\analyzer_odds`. `ReloadSec = 15`.
