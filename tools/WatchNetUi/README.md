# WatchNetUi

WPF-монитор живого `--watch-net` (шаблона WinUI 3 в SDK не было — Windows UI на WPF).

Каждый «воркер» — отдельный процесс `python -m analyzer --watch-net` (не поток: GIL / numpy). Лимит **8** воркеров — как `JOBS_CAP` в `analyzer/watch_pool.py`. При 16–20 параллельных `export_net` машина thrash'ится: CPU крутится, CSV почти не обновляются. Запрошенное число > 8 UI обрезает до 8.

## Запуск

```text
dotnet run --project tools/WatchNetUi/WatchNetUi/WatchNetUi.csproj -c Release
```

Перед стартом остановите `python -m analyzer --watch-net-pool` и другой WatchNetUi — два писателя на одни CSV.

## Кнопки

| кнопка | поведение |
|---|---|
| **Старт всех** | N воркеров (≤8) делят **все** тикеры round-robin через `--watch-only`. Раньше N слотов означало «только N тикеров навсегда» — так больше не работает |
| **Старт выбранных** | если выбранных ≤ N — по процессу на тикер; если больше — пул только по выбранным |
| **Стоп …** | гасит шард целиком (у `--watch-only` нельзя выкинуть один тикер из процесса) |

## Термины

| слово | смысл |
|---|---|
| **export** | один полный `export_net` по одному инструменту (~1–2 мин): пачки, аналоги, MLP, запись CSV M1…D1. В логе: `compute SEC …`. В шарде за poll — **не больше одного** (fair) |
| **круг** | время полного прохода шарда: ≈ `число тикеров в шарде × длительность export` |
| **fair** | внутри шарда сначала давно не обновлённые; горячий тикер не голодает остальных |
| **возраст** | `сейчас − mtime` net CSV на диске, не «сколько в пуле». 31 ч = файл не переписывали с того момента |

Дорогое в export — расчёт по окну M1 (аналоги + MLP), не запись CSV по ТФ. Отключить вывод на D1/H4/M30/M1 почти **не** ускоряет: M10 всё равно строится из полного M1-ряда. Подробнее: [docs/analyzer-net.md](../../docs/analyzer-net.md).

## Колонки

| колонка | смысл |
|---|---|
| Воркер | `w1`…`w8` — id шарда |
| Статус / PID | процесс жив |
| Последнее обновление | mtime самого свежего net CSV (M1…D1) |
| Возраст | возраст этого mtime |
| До обновления | **считает сейчас** — шард в `compute` по этому тикеру; **в очереди** — шард считает соседа; иначе countdown до `last + круг` |
| Деталь | bars новее CSV, fair среди K, кого считает шард |

## Лог

Строки stdout/stderr воркеров. `Dispatcher.BeginInvoke`, чтобы полный pipe не стопорил export.
